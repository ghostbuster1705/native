# VELO — Fast Fashion React Native App

Single-file Expo Snack app inspired by Zalando-style fast fashion e-commerce.

## Run in Expo Snack

1. Open [https://snack.expo.dev/](https://snack.expo.dev/)
2. Replace the contents of `App.js` with the code from this repository
3. Ensure these dependencies are present (Snack usually includes them by default):
   - `expo-linear-gradient`
   - `@expo/vector-icons`
   - `react-native-safe-area-context`
4. Scan the QR code with **Expo Go** on your phone

## Features

- Hero carousel with auto-scroll and parallax
- Product catalog with categories, search, and sorting
- Product detail with image gallery, size/color picker
- Wishlist and shopping bag with quantity controls
- Animated tab bar, press feedback, toasts, and checkout flow
- Profile with loyalty card

## File

All app code lives in a single `App.js` — ready to paste into Snack.
